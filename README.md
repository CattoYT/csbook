Any AI used within this project will be explicitly labelled within the file it's used in. It's usage will remain incredibly limited within this book and will be rewritten as soon as possible.

See the introduction page for more detailed information.

To host locally:

```
git clone https://github.com/cattoyt/csbook
cd csbook
cargo install mdbook
mdbook serve 
```

If you see an error relating to no-html-extension in book.toml, please check [this issue](https://github.com/rust-lang/mdBook/pull/3047) for why. I also [have a fork with a built version of mdbook with those patches](https://github.com/CattoYT/mdBook/releases/tag/a)
