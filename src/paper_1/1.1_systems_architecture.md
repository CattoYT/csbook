## TL;DR

Computer systems use a processor to fetch, decode, and execute instructions, and
use memory, buses, and peripherals to move and store data.

- The **CPU** contains the control unit, ALU, registers, clock, and buses. It
  repeatedly performs the **fetch-decode-execute cycle**, and can improve
  throughput through pipelining.
- **RISC** processors use a small set of simple instructions, while **CISC**
  processors use a larger set of more complex instructions. Multiple cores,
  threads, and specialised processors such as GPUs can provide parallel
  processing, although parallelism adds coordination overhead and complexity.
- **Input devices** send data to a computer and **output devices** present the
  results. Storage technologies have different trade-offs: HDDs offer
  inexpensive capacity, SSDs offer speed and durability, optical media can be
  useful for distribution or archiving, and virtual storage can combine drives
  and provide redundancy.
- **RAM** is fast, volatile primary storage used while programs run, while
  **ROM** is non-volatile memory commonly used for firmware.
