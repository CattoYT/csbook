# Software and software development
![GitHub last commit](https://img.shields.io/github/last-commit/cattoyt/csbook?path=src%2Fpaper_1%2F1.2_software_and_software_development.md&label=Last%20updated)

## TL;DR

Software is the set of programs that controls hardware and performs tasks for
users. **Systems software** manages the computer and provides a platform for
applications, while **application software** performs user-focused tasks.

- An **operating system** manages **resources**, **files**, **memory**,
  **interrupts**, and
  processes; provides security, a user interface, and a platform for software;
  and includes **utilities** such as compression and disk management. Memory
  can be managed with **paging**, **segmentation**, and **virtual memory**.
  Scheduling algorithms include **round robin**, **first come first served**,
  **multi-level feedback queues**, **shortest job first**, and
  **shortest remaining time**.
- Operating systems may be **distributed**, **embedded**, **multitasking**,
  **multi-user**, or **real-time**. **BIOS** starts and checks the computer
  before loading the OS, **device drivers** allow the OS to communicate with
  peripherals, and **virtual machines** emulate a computer so that
  **intermediate code** or another operating system can run.
- Applications can be **open source** or **closed source**. **Translators**
  convert source code into executable form: **compilers** translate a whole
  program, **interpreters** execute it statement by statement, and
  **assemblers** translate assembly language. Compilation includes
  **lexical analysis**, **syntax analysis**, **code generation**, and
  **optimisation**; **linkers** combine object code with libraries and
  **loaders** place programs into memory.
- Software development follows a lifecycle of **analysis**, **design**,
  **development**, **testing**, **implementation**, **evaluation**, and
  **maintenance**. **Waterfall** is sequential, while **agile**,
  **extreme programming**, **spiral**, and **rapid application development**
  are iterative approaches with different strengths, risks, and suitable
  project types.
- **Programming paradigms** describe different ways of solving problems.
  **Procedural** languages use sequential procedures and functions;
  **object-oriented** languages use **classes**, **objects**, **attributes**,
  **methods**, **inheritance**, **encapsulation**, and **polymorphism**;
  **declarative** and **functional** languages describe the required result or
  transformations. **Assembly** is low-level and processor-specific, and uses
  addressing modes such as **immediate**, **direct**, **indirect**, and
  **indexed**.
