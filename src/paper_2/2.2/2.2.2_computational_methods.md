# Computational Methods

## Features that make a problems solvable by computational methods
Not all problems can be solved by computational methods. The famous example is the halting problem (Tom Scott made a good video about it [here](https://www.youtube.com/watch?v=eqvBaj8UYz4)). The halting problem is a decision problem that asks whether a given program will finish running or continue to run forever. It has been proven that there is no general algorithm that can solve this problem for all possible program-input pairs. 

A problem that can be solved by computational methods is known as **computable** and typically consist of inputs, outputs, and various calculations. However, some computable problems may be too complex to solve in a reasonable amount of time, and are known as **intractable**. Processing power and memory etc are limited, and some problems may require more resources than are available.

## Problem decomposition
Decomposing a problem is the process of breaking it down into smaller, more manageable sub-problems. This can make it easier to understand and solve the overall problem. Each sub-problem can be solved independently, and the solutions can then be combined to solve the original problem. 

When decomposing a problem, it is important to consider how the sub-problems relate to each other and how they will be combined to form a complete solution. This may involve identifying dependencies between sub-problems and determining the order in which they should be solved.

## Divide and Conquer
Divide and conquer is a problem-solving technique that involves breaking a problem down into smaller sub-problems, solving each sub-problem independently, and then combining the solutions to solve the original problem. This approach can be particularly effective for problems that can be divided into smaller, similar sub-problems.

Algorithms are often divide and conquer, such as the merge sort algorithm, which sorts an array by dividing it into two halves, sorting each half independently, and then merging the sorted halves back together. This approach can be more efficient than sorting the entire array at once, especially for large arrays. However, it is also used in binary search, quick sort, and many other places.

## Abstraction
>[!NOTE]
> Abstraction is covered in 2.1.1, so the following will be a summary.

Abstraction is the process of removing unnecessary details and focusing on the important aspects of a problem. This can make it easier to understand and solve the problem, as well as making it easier to communicate the solution to others.

There are several methods of abstraction, including abstraction by generalisation, abstraction by encapsulation, and abstraction by modularity. Each of these methods can be used to simplify a problem and make it more manageable.

## Problem solving
There are several different types of problem solving techniques that can be used to solve computational problems. These include:
- **Data mining**: The process of discovering patterns and relationships in large datasets. This can be used to identify trends, make predictions, and inform decision-making. This allows predictions to be made based on data, and can be used in a variety of fields, such as finance, healthcare, and marketing. This is also what Palantir does and often results in GDPR violations and ethical issues.
- **Backtracking**: A problem-solving technique that involves exploring all possible solutions to a problem and eliminating those that do not meet the requirements. This can be used to find the optimal solution to a problem, and is often used in combinatorial problems, such as the traveling salesman problem, and Dijkstra's algorithm. Backtracking can be implemented using recursion, and is often used in conjunction with other problem-solving techniques, such as divide and conquer.
- **Heuristics**: A problem-solving technique that involves using rules of thumb or educated guesses to find a solution to a problem. This can be used when the problem is too complex to solve using traditional methods (intractable), and can help to find a good enough solution in a reasonable amount of time. Heuristics can be used in a variety of fields, such as artificial intelligence, operations research, and decision-making. The A* algorithm is a well-known example of a heuristic algorithm.
- **Performance modelling**: The process of creating a mathematical model of a system or process in order to predict its performance under different conditions. This can be used to identify bottlenecks, optimise performance, and inform decision-making. Performance modelling can be used in a variety of fields, such as computer science, engineering, and operations research. This is cheaper, less time-consuming, and less risky than testing a system in the real world, and can be used to inform decisions about system design, resource allocation, and performance optimisation.

## Pipelining
Pipelining in programming is where multiple parts of the program are developed in parallel. The output of one process becomes the input of the next process.

## Visualisation
Data visualisation is the process of representing data in a graphical or visual format. This can make it easier to understand and interpret the data, as well as identify patterns and trends. Data visualisation can be used in a variety of fields, such as business, healthcare, and scientific research. Common types of data visualisation include bar charts, line graphs, scatter plots, and heat maps.
