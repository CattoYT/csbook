There are three different types of algorithms you need to know for A Level:
- Searching: linear and binary search
- Sorting: bubble, insertion, merge, and quick sort
- Pathfinding: Dijkstra and A*

## The theory of algorithms
- The code you write will always be an **implementation** of an algorithm.
- There are a number of steps you need to take when creating an algorithm: defining inputs and outputs,
and mapping the inputs such that if the same set of inputs are given, the same set out outputs will be produced
(predictability).
- The set of possible inputs is known as the **domain** (like in maths), and the range of possible outputs
is known as the **codomain**. The algorithm can be thought of as a function (f(x)) that converts domain values into codomain values.
- Standard design tools for showing the mapping of inputs to outputs are **flowcharts** and **pseudocode**. 
- These tools allow the design to show the key steps of the algorithm (main techniques, data structures, variables, desicions, and processes).
- Once the algorithm is written, we have to check that the algorithm gives a predictable and repeatable output that is correct for the domain: this is the point of **trace tables**.

## Efficiency
- Algorithms should be made efficient: they should be optimal in terms of **space** (system resources)
and **time**.
- Time complexity can be represented using Big O notation: this is written as O(complexity). For example, O(n²) means that the time the algorithm takes is roughly proportional to the square of the size of the inputs. This is considered a fairly bad time complexity, and the absolute best is O(1), where the algorithm takes the same amount of time no matter the size of the input.
- Time complexity is usually improved by using less steps in the algorithm.
- Space complexity can be improved by loading less things into RAM (less variables, reusing code, etc).
- The third component that makes up efficiency is **scalability**: how does the time and space complexity change as the number of inputs are changed?.
